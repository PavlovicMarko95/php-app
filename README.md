# PHP News App

## Features
- View all news for all users
- Admin can add news
- Logged-in users can comment
- Non-logged-in users can only read news

## Technologies
- PHP
- MySQL / SQL Server
- OOP (Vest, Korisnik, Komentar, Baza)

## Database
Database script is included (vesti.sql).
